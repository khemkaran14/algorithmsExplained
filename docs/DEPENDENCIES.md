# Dependency security maintenance

The 2026-10-16 security checkpoint uses a frozen pnpm lockfile, patched Auth.js and locale packages, and explicit transitive updates. `pnpm audit:security` is enforced in CI. The current full dependency inventory has no reported advisories. Re-run the audit after every lockfile update; this result describes the checked inventory.

Use Node.js 22.12+ within the 22 LTS series, Node 24, or a later version supported by the package engine declaration. pnpm remains pinned to 10.28.2. Vitest 5 replaces the older worker-pool dependency while retaining the existing test suite.
