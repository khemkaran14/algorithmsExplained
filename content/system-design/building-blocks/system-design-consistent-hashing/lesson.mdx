# System Design Consistent Hashing

## Hook

Adding a stop to a circular delivery route should affect nearby ownership, not renumber every address.

## Code

The four references implement the core model or its decision round. Queue/inbox and local ledger atomicity are explicit assumptions. Reference inputs are fully validated/defaulted by the lesson; standalone callers must provide the shown fields.

## When to use

Use for partition ownership reasoning when node membership changes.

## Interview pitfalls

Consistent placement is separate from replication and online migration. Small samples, hot keys and failure correlation can still produce severe imbalance.
