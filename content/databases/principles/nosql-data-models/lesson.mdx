## How it works

Owner documents embed the owner’s order records. Key-value access uses explicit record keys and optionally maintained owner references. Wide-column layout groups by owner and sorts by created time so binary bounds restrict an interval. Graph layout builds directed adjacency and uses deduplicated breadth-first neighborhood expansion. Remaining amount/time predicates still require filtering.
