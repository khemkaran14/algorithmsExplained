## How it works

1. Treat the array as complete-tree level order.
2. Emit root before children for preorder.
3. Emit between left and right for inorder.
4. Emit after children for postorder, or use FIFO level order.

## Try it

Predict the branch, repair, visited node or range block. Try the single-element case, then use a larger seeded input.

## Complexity

O(n) time; O(h) DFS stack or O(w) level frontier. Traversal order changes the output without changing the tree. The input is a complete binary tree, not an implicit BST; inorder is sorted only if the tree already satisfies BST ordering.

## Code

## When to use

Use preorder for structural serialization, postorder for bottom-up computation and BFS for layers.

## Interview pitfalls

Do not infer BST ordering merely because the tree is binary.
