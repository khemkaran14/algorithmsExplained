# Big-O notation

## Hook

Like counting plates to wash, input size tells us how much work remains.

## Watch

Use the player above to run, pause, scrub, or step backwards through a deterministic trace.

## How it works

1. Visit each input once.
2. Increment the reads counter.
3. Compare operation growth as input grows.

## Try it

Switch to Try mode and predict each operation before revealing its result.

## Complexity

A single pass takes linear time. Use best, average and worst presets to compare measured counters. The chart plots actual reads and comparisons for n = 8, 16, 32 and 64.

## Code

Choose JavaScript, Python, Java or C++ in the synchronized code panel.

## When to use

Summing a stream or scanning a list.

## Interview pitfalls

Big-O ignores constants; it does not predict exact milliseconds.
