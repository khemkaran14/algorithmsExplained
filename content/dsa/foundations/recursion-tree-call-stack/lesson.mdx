# Recursion Tree Call Stack

## Hook

A family tree records all descendants, while a finger tracing one branch records only the current route.

## Watch

The tree is every call. The stack is one active path. Explore the validated presets and edit the input to check a boundary case.

## How it works

1. Create a node for every naive Fibonacci call.
2. Push the call onto the active stack.
3. Visit its n−1 and n−2 children unless it is a base case.
4. Add their results, pop the call and return.

## Complexity

Naive Fibonacci repeats subproblems exponentially, while the active call stack has linear depth. Storing the entire educational call tree is additional visualization memory. The chart labels identify actual counters or explicitly modeled recurrence work; display snapshots are not charged to the underlying algorithm.

## Code

Switch among JavaScript, Python, Java and C++. The active conceptual stage and live variables connect the code to the trace.

## When to use

Use recursion trees to find repeated work and the call stack to understand execution order.

## Interview pitfalls

Do not confuse the number of tree nodes with active stack depth. This uncached demonstration is intentionally capped at n=8.
