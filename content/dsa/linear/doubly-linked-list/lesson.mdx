# Doubly Linked List

## Hook

Each carriage in a train connects to both the carriage before it and the one after it.

## Watch

Two links. Two directions. Track the pointer, capacity or index variables as each operation executes.

## How it works

1. Store previous and next links.
2. Repair both directions when inserting.
3. Search for a key if its node is not already known.
4. Delete a known node by joining its previous and next neighbors.

## Complexity

A known node can be removed in O(1), but locating it by key still costs O(n). Each node stores an extra previous link. Visualization snapshots are separate from the data structure’s logical operation costs.

## When to use

Use it for deques and caches that already have a direct reference to the node being moved or removed.

## Interview pitfalls

Repair both neighbor links and the head/tail pointers. Forgetting one direction leaves a broken invariant.
