# Circular Queue

## Hook

The hand on a clock wraps to the beginning instead of extending the dial.

## Watch

Reuse a fixed buffer without moving its contents. Track the pointer, capacity or index variables as each operation executes.

## How it works

1. Track head, tail and size.
2. Reject or make room before enqueuing into a full buffer.
3. Advance each pointer modulo capacity.
4. Use size to distinguish full from empty.

## Complexity

Enqueue and dequeue are O(1); the reserved buffer uses O(k) capacity. This demonstration dequeues when full so wraparound becomes visible. Visualization snapshots are separate from the data structure’s logical operation costs.

## When to use

Use bounded circular buffers for predictable-capacity queues, streaming and producer-consumer designs with an explicit concurrency protocol.

## Interview pitfalls

Head equal to tail is ambiguous without a size or extra-slot convention. Never silently overwrite unread data unless overwrite behavior is part of the design.
