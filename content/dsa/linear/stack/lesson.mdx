# Stack

## Hook

A stack of plates only lets you take the plate on top.

## Watch

Use the player above to run, pause, scrub, or step backwards through a deterministic trace.

## How it works

1. Push adds a value at the top.
2. Peek reads the top without removing it.
3. Pop removes the most recently added value.

## Try it

Switch to Try mode and predict each operation before revealing its result.

## Complexity

Push and pop touch only one end. Use best, average and worst presets to compare measured counters. The chart plots actual reads and comparisons for n = 8, 16, 32 and 64.

## Code

Choose JavaScript, Python, Java or C++ in the synchronized code panel.

## When to use

Undo history, expression parsing and depth-first traversal.

## Interview pitfalls

Always check for an empty stack before a pop or peek.
