# Deque

## Hook

A double-ended line allows arrivals and departures at both entrances.

## Watch

Either end can be the right end. Track the pointer, capacity or index variables as each operation executes.

## How it works

1. Keep both head and tail links.
2. Push at the selected end.
3. Pop at the selected end.
4. Repair both endpoints when the deque becomes empty.

## Complexity

A doubly linked implementation performs each end operation in O(1) time and stores O(n) nodes. Visualization snapshots are separate from the data structure’s logical operation costs.
