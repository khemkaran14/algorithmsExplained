# Binary search

## Hook

Like opening a dictionary in the middle, each comparison rules out half the remaining pages.

## Watch

Use the player above to run, pause, scrub, or step backwards through a deterministic trace.

## How it works

1. Start with sorted values.
2. Compare the middle value to the target.
3. Keep only the half that could contain the target.
4. Stop at a match or an empty interval.

## When to use

Searching sorted random-access data.

## Interview pitfalls

An unsorted input breaks the invariant; off-by-one boundaries cause missed values.
