# Bfs

## Hook

A ripple reaches every nearby vertex before the next layer.

## Watch

Explore complete distance layers. Edit the graph JSON to add a cycle, isolate a vertex or change an edge weight. Nodes are numbered from zero.

## How it works

1. Mark the starting vertex on enqueue.
2. Remove the oldest frontier vertex.
3. Enqueue each still-unseen outgoing neighbor.

## Try it

Predict the next frontier decision or edge operation before revealing it. Compare a connected graph with the same graph after removing an important edge.

## Complexity

O(V+E) time and O(V) traversal workspace. Every reached vertex enters the FIFO frontier exactly once, and its outgoing adjacency list is scanned once. Discovery layers give shortest hop distances. The counters count teaching operations; animation duration is not a CPU benchmark.

## Code

The four references show the core operation. Adjacency-list inputs use zero-based vertex indices. Weighted references use (neighbor,weight) pairs or explicit edge triples. Validate the graph assumptions before calling standalone code.

## When to use

Use for unweighted shortest hops and level exploration.

## Interview pitfalls

Edge weights are ignored for hop distances; use Dijkstra or Bellman–Ford for weighted routes.
