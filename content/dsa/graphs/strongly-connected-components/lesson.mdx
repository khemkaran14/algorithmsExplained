# Strongly Connected Components

## Hook

A directed region is one component only if every member can get back to every other.

## Watch

Group mutually reachable vertices. Edit the graph JSON to add a cycle, isolate a vertex or change an edge weight. Nodes are numbered from zero.

## How it works

1. Collect DFS finish order and traverse the transpose for Kosaraju.
2. Alternatively track active-stack low links for Tarjan.
3. Assign every vertex to one maximal mutually reachable group.

## Try it

Predict the next frontier decision or edge operation before revealing it. Compare a connected graph with the same graph after removing an important edge.

## Complexity

O(V+E). Do not use undirected components or reachability from a single seed as a substitute for SCCs. The counters count teaching operations; animation duration is not a CPU benchmark.

## Code

The four references show the core operation. Adjacency-list inputs use zero-based vertex indices. Weighted references use (neighbor,weight) pairs or explicit edge triples. Validate the graph assumptions before calling standalone code.

## When to use

Use for condensation DAGs, cyclic dependency groups and directed connectivity.

## Interview pitfalls

Do not use undirected components or reachability from a single seed as a substitute for SCCs.
