# Max Flow

## Hook

Water can be rerouted through a network until no source-to-sink residual route remains.

## Watch

Residual reverse arcs let you undo old choices. Edit the graph JSON to add a cycle, isolate a vertex or change an edge weight. Nodes are numbered from zero.

## How it works

1. Build a paired reverse arc for each capacity edge.
2. Find a BFS augmenting path for Edmonds–Karp, or a DFS path for integer Ford–Fulkerson.
3. Add the bottleneck and update both residual directions.

## Try it

Predict the next frontier decision or edge operation before revealing it. Compare a connected graph with the same graph after removing an important edge.

## Complexity

Edmonds–Karp O(VE²); integer DFS Ford–Fulkerson O(E·|f\*|). Residual reverse arcs are separate from original opposite-direction edges. The final reachable cut certifies the answer. Source equal to sink returns zero in this teaching convention. The counters count teaching operations; animation duration is not a CPU benchmark.
