# Prim Mst

## Hook

Expand a connected region with the cheapest edge that reaches a new vertex.

## Watch

Grow a tree across its cheapest frontier. Edit the graph JSON to add a cycle, isolate a vertex or change an edge weight. Nodes are numbered from zero.

## How it works

1. Seed one unvisited component.
2. Pop its cheapest crossing edge.
3. Add a fresh vertex and offer its outgoing frontier edges.

## Try it

Predict the next frontier decision or edge operation before revealing it. Compare a connected graph with the same graph after removing an important edge.

## Complexity

O((V+E) log(V+E)). Restart in disconnected components; negative edge weights are allowed for MSTs. The counters count teaching operations; animation duration is not a CPU benchmark.

## Code

The four references show the core operation. Adjacency-list inputs use zero-based vertex indices. Weighted references use (neighbor,weight) pairs or explicit edge triples. Validate the graph assumptions before calling standalone code.

## When to use

Use for minimum spanning forests using adjacency lists and a priority queue.

## Interview pitfalls

Restart in disconnected components; negative edge weights are allowed for MSTs.
