# Floyd Warshall

## Hook

Improve every city pair by asking whether a permitted stop makes the route cheaper.

## Watch

Allow one more intermediate vertex. Edit the graph JSON to add a cycle, isolate a vertex or change an edge weight. Nodes are numbered from zero.

## How it works

1. Initialize diagonal zero and edge weights.
2. For each k, compare d[i][j] with d[i][k]+d[k][j].
3. Mark pairs that can pass through a negative cycle as unbounded below.

## Try it

Predict the next frontier decision or edge operation before revealing it. Compare a connected graph with the same graph after removing an important edge.

## Complexity

O(V³) time and O(V²) workspace. The k loop must be outermost for this invariant. A negative diagonal identifies a negative cycle. The counters count teaching operations; animation duration is not a CPU benchmark.

## Code

The four references show the core operation. Adjacency-list inputs use zero-based vertex indices. Weighted references use (neighbor,weight) pairs or explicit edge triples. Validate the graph assumptions before calling standalone code.

## When to use

Use for all-pairs shortest paths on modest dense graphs.
