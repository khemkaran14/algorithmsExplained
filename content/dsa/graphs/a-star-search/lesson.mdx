# A Star Search

## Hook

A route planner combines travelled cost with a lower bound on what remains.

## Watch

Prioritize distance so far plus a safe estimate. Edit the graph JSON to add a cycle, isolate a vertex or change an edge weight. Nodes are numbered from zero.

## How it works

1. Compute a consistent geometric lower bound.
2. Pop the smallest g+h frontier priority.
3. Relax outgoing edges and stop when the target is settled.

## Try it

Predict the next frontier decision or edge operation before revealing it. Compare a connected graph with the same graph after removing an important edge.

## Complexity

O((V+E) log(V+E)) with a consistent heuristic. The heuristic uses the smallest edge cost per drawn unit; arbitrary geometric distances would overestimate on custom weighted graphs. Zero-cost edges may reduce h to zero. The counters count teaching operations; animation duration is not a CPU benchmark.

## Code

The four references show the core operation. Adjacency-list inputs use zero-based vertex indices. Weighted references use (neighbor,weight) pairs or explicit edge triples. Validate the graph assumptions before calling standalone code.

## When to use

Use to guide shortest-path search toward one target when a useful lower bound is available.
