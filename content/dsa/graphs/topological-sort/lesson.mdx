# Topological Sort

## Hook

Schedule a task only after its prerequisites have been removed.

## Watch

Dependencies must come before dependents. Edit the graph JSON to add a cycle, isolate a vertex or change an edge weight. Nodes are numbered from zero.

## How it works

1. Count incoming edges.
2. Remove zero-indegree vertices using Kahn’s queue.
3. Alternatively reverse DFS finish order after checking back edges.

## Try it

Predict the next frontier decision or edge operation before revealing it. Compare a connected graph with the same graph after removing an important edge.

## Complexity

O(V+E). A partial Kahn result is not a valid complete order when a cycle remains. The counters count teaching operations; animation duration is not a CPU benchmark.

## Code

The four references show the core operation. Adjacency-list inputs use zero-based vertex indices. Weighted references use (neighbor,weight) pairs or explicit edge triples. Validate the graph assumptions before calling standalone code.

## When to use

Use for dependency scheduling on a directed acyclic graph.

## Interview pitfalls

A partial Kahn result is not a valid complete order when a cycle remains.
