# Bridges Articulation Points

## Hook

A bridge is a road whose removal disconnects an otherwise reachable region.

## Watch

Can this subtree return without its parent edge? Edit the graph JSON to add a cycle, isolate a vertex or change an edge weight. Nodes are numbered from zero.

## How it works

1. Record DFS discovery times.
2. Propagate the earliest reachable ancestor as low-link values.
3. Use low[child]>disc[parent] for bridges and the articulation rules for vertices.

## Try it

Predict the next frontier decision or edge operation before revealing it. Compare a connected graph with the same graph after removing an important edge.

## Complexity

O(V+E). The DFS root is an articulation point only with multiple DFS children; nonroots use a different test. The counters count teaching operations; animation duration is not a CPU benchmark.

## Code

The four references show the core operation. Adjacency-list inputs use zero-based vertex indices. Weighted references use (neighbor,weight) pairs or explicit edge triples. Validate the graph assumptions before calling standalone code.

## When to use

Use for undirected single-edge or single-vertex connectivity vulnerabilities.
