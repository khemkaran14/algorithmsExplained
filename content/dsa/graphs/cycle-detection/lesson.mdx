# Cycle Detection

## Hook

Following dependencies back into the active chain makes a circular dependency.

## Watch

A return edge closes a loop. Edit the graph JSON to add a cycle, isolate a vertex or change an edge weight. Nodes are numbered from zero.

## How it works

1. Track unseen, active and finished vertices.
2. For directed graphs, detect an edge to an active vertex.
3. For undirected graphs, skip only the incoming edge before checking visited neighbors.

## Try it

Predict the next frontier decision or edge operation before revealing it. Compare a connected graph with the same graph after removing an important edge.

## Complexity

O(V+E). A directed edge to a finished vertex alone does not prove a cycle. The counters count teaching operations; animation duration is not a CPU benchmark.

## Code

The four references show the core operation. Adjacency-list inputs use zero-based vertex indices. Weighted references use (neighbor,weight) pairs or explicit edge triples. Validate the graph assumptions before calling standalone code.

## When to use

Use for validating dependency graphs and forest assumptions.
