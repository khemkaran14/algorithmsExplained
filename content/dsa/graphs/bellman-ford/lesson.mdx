# Bellman Ford

## Hook

Repeatedly compare every offered route until no shorter route remains.

## Watch

Allow one more edge per full pass. Edit the graph JSON to add a cycle, isolate a vertex or change an edge weight. Nodes are numbered from zero.

## How it works

1. Initialize the start at zero.
2. Relax all directed edge arcs for up to V−1 passes.
3. Check a final possible improvement and mark all downstream negative-cycle effects.

## Try it

Predict the next frontier decision or edge operation before revealing it. Compare a connected graph with the same graph after removing an important edge.

## Complexity

O(VE). A negative cycle unreachable from the start does not make this source’s distances unbounded. The counters count teaching operations; animation duration is not a CPU benchmark.

## Code

The four references show the core operation. Adjacency-list inputs use zero-based vertex indices. Weighted references use (neighbor,weight) pairs or explicit edge triples. Validate the graph assumptions before calling standalone code.

## When to use

Use when reachable negative edges may occur.
