# Bubble sort

## Hook

Like bubbles rising through water, each pass carries the largest remaining value to the right.

## Watch

Use the player above to run, pause, scrub, or step backwards through a deterministic trace.

## How it works

1. Compare neighboring values.
2. Swap only if the left value is larger.
3. Shorten the unsorted interval.
4. Stop after a pass without swaps.

## Try it

Switch to Try mode and predict each operation before revealing its result.

## Complexity

Nested passes make the average and worst cases quadratic. Use best, average and worst presets to compare measured counters. The chart plots actual reads and comparisons for n = 8, 16, 32 and 64.

## Code

Choose JavaScript, Python, Java or C++ in the synchronized code panel.

## When to use

Tiny or nearly sorted inputs and learning stable, in-place sorting.

## Interview pitfalls

Do not use it for large random arrays; quadratic comparisons dominate.
