# Edit Distance

## Hook

Transform one message into another by the cheapest sequence of unit edits.

## Watch

Choose a final edit between prefixes. Change the input to test a base case, a repeated subproblem and an unreachable or constrained state where applicable.

## How it works

1. Initialize empty-prefix insertion and deletion costs.
2. Use a free matching diagonal.
3. On mismatch, minimize insertion, deletion and substitution plus one.
4. Backtrack optimal predecessor states.

## Try it

Predict a recurrence choice, comparison or valid search branch. Explain which stored state or constraint makes the next decision correct.

## Complexity

O(mn) time and O(mn) reconstruction space. The player states the recurrence or greedy/search invariant and counts teaching operations rather than measuring animation time.

## Code

The four reference languages show the core operations under the same bounded input assumptions. Full tables preserve predecessor information for reconstruction; a table-only reference returns those states for the caller to backtrack. Backtracking references include N-Queens, subsets, permutations and a budgeted 9×9 Sudoku solver.

## When to use

Use for Levenshtein similarity, typo correction and transformation costs.

## Interview pitfalls

Transposition is not a one-step operation in this unit-cost Levenshtein model.
