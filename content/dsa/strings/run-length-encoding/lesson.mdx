# Run Length Encoding

## Hook

Bundle consecutive identical tiles into a tile label and a count.

## Watch

Count equal neighbors, not equal characters everywhere. Use a repeated-character input and compare the resulting counters with a less repetitive example.

## How it works

1. Compare the next character with the active run.
2. Extend an equal run or start a new one.
3. Decode each [character,count] pair by repetition.

## Try it

Predict a character comparison, run extension, palindrome expansion or merge frequency. Step back and explain which stored state avoided repeated work.

## Complexity

O(n) time and O(r) output runs. The player explains the relevant invariant and counts actual comparisons, reads and writes. Output storage is reported separately when it grows with the result.

## Code

The four references assume the lesson’s printable ASCII input contract. The foundation Strings lesson separately explains Unicode code points and UTF-16 units. Pattern inputs must be nonempty; text may be empty for matching. Huffman and palindrome inputs must be nonempty.

## When to use

Use for long uniform runs such as simple masks and repeated symbols.

## Interview pitfalls

Alternating data may expand. Explicit pairs avoid ambiguity when the source itself contains digits.
