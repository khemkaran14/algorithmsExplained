# Kmp

## Hook

Keep the part of the stencil that already matches instead of starting from scratch.

## Watch

A mismatch can preserve a matching prefix. Use a repeated-character input and compare the resulting counters with a less repetitive example.

## How it works

1. Build the longest proper-prefix/suffix table.
2. Compare the current text and pattern characters.
3. Follow prefix fallback links after mismatch.
4. After a match, retain the longest overlap prefix.

## Try it

Predict a character comparison, run extension, palindrome expansion or merge frequency. Step back and explain which stored state avoided repeated work.

## Complexity

O(n+m) time and O(m) auxiliary space. The player explains the relevant invariant and counts actual comparisons, reads and writes. Output storage is reported separately when it grows with the result.

## Code

The four references assume the lesson’s printable ASCII input contract. The foundation Strings lesson separately explains Unicode code points and UTF-16 units. Pattern inputs must be nonempty; text may be empty for matching. Huffman and palindrome inputs must be nonempty.

## When to use

Use when guaranteed linear matching matters, especially for repeated prefixes.

## Interview pitfalls

Fallback uses prefix[j−1], and a full match must preserve overlapping candidates.
