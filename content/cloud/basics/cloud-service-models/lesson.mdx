# Cloud Service Models

## Hook

Renting infrastructure, a managed platform and finished software shifts different operational duties.

## Watch

Choose AWS or GCP mapping, change one validated model parameter and load the trace. Provider labels identify concepts; the model never provisions resources or calls a provider account.

## How it works

Compare IaaS, PaaS and SaaS against explicit task ownership. IaaS exposes guest OS/runtime/app maintenance, PaaS manages the runtime, and SaaS manages application source. Customer tenant-data policy and account credentials remain customer choices.

### AWS and GCP comparison

AWS: EC2 IaaS / managed platform / SaaS concepts. GCP: Compute Engine IaaS / App Engine / Google SaaS concepts. This is a declared baseline, not every provider product contract. Google Workspace is a Google SaaS example, not a resource inside a GCP project. Actual contract, configuration and business requirements define each responsibility.
