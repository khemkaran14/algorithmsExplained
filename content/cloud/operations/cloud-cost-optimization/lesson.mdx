# Cloud Cost Optimization

## Hook

A cache can reduce database work while adding more to the bill than it saves.

## Watch

Load the average scenario and step through the initial state before playing. Read the variables and final result, then switch to the worst scenario. Pause before a decision and predict which explicit condition determines the next action.

## How it works

Transparent user-supplied rates estimate either provisioned instance-hours or origin request charges, storage over a 730-hour month, client egress using decimal KB/GB, and a flat cache rate. Origin hits reduce origin requests but not bytes still delivered to clients. The result lists components rather than hiding assumptions in a total.

## Try it

Compare cache disabled and enabled in per-request mode. Then use instances with very low traffic and explain why provisioned compute cost persists. Change egress rate and inspect which component changes. In Try mode, choose the next modeled decision and use the hint to inspect its preconditions. Explain a changed result using the actual input rather than the provider logo.

## Complexity

The player displays the model's operation metric and declared bounds. Compare best, average and worst presets before changing only one parameter. Simulation operation counts are different from provider quotas, cloud bills, throughput benchmarks and wall-clock service latency.

## Code

References implement the same transparent component arithmetic. No pricing API or actual billing account is read. All four languages show local reference logic rather than provider SDK calls. Validate inputs and account for the unmodeled production concerns before adapting a reference.

## When to use

Use this scenario when reviewing AWS workload cost assumptions or Google Cloud workload cost assumptions: identify the workload assumption, failure boundary and evidence needed for the selected design. Record one alternative and the constraint it changes.

## Interview pitfalls

These are assumed USD inputs, not current provider pricing, quotes or a complete bill. Duration, tiers, commitments, taxes, minimum charges and regional transfers are excluded; verify provider calculators and actual invoices.

## Quiz

Answer the mechanism question, distinguish the exercise from a real cloud operation, and justify a controlled failure experiment. Re-run the scenario if your prediction disagrees with the traced state.
