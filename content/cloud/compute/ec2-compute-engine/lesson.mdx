## How it works

Adjust app replicas and per-replica CPU work capacity. Requests enter the app pool, then the separately limited database; queues, rejected requests and completions are all accounted for. The AWS/GCP toggle changes component mappings, not a universal hardware performance claim.

### AWS and GCP comparison

AWS: EC2 / Compute Engine virtual machines. GCP: EC2 / Compute Engine virtual machines. EC2 and Compute Engine expose different instance families, images, disks and billing choices. The model uses assumed work units, not measured vCPU throughput or current pricing. OS patching, image policy, IAM and network configuration remain part of VM operation.
