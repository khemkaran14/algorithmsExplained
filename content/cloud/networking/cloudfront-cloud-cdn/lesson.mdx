## Hook

## How it works

The edge-cache path is checked before the modeled origin region. Cache hits complete at the edge; misses still need healthy app/database work. A seeded hit probability is an illustrative traffic assumption, not an implementation of HTTP cache-control or provider invalidation.

### AWS and GCP comparison

AWS: CloudFront / Cloud CDN. GCP: CloudFront / Cloud CDN. CloudFront and Cloud CDN differ in origin configuration and invalidation APIs. Cache keys, authorization variation, TTL, stale policy and private content require explicit security design. Never cache personalized app responses under a shared key.
