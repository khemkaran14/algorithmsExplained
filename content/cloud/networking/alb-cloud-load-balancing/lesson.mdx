# Alb Cloud Load Balancing

## Hook

A load balancer distributes accepted work among healthy targets; it cannot create database capacity.

## Watch

Choose AWS or GCP mapping, change one validated model parameter and load the trace. Provider labels identify concepts; the model never provisions resources or calls a provider account.

## How it works

Round-robin service work goes to healthy app replicas, with a separate database queue and budget. Fail one app target or the database and inspect the completed, pending and rejected counts.

### AWS and GCP comparison

AWS: Application Load Balancer / Cloud Load Balancing. GCP: Application Load Balancer / Cloud Load Balancing. These are conceptual mappings. AWS ALB and Google Cloud Load Balancing have product-specific scopes, health checks, backends, session behavior and layer-7 features; this trace is not their control-plane implementation.
