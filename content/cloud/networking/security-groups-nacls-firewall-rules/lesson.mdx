## How it works

Stateful allow-list mode admits a reverse packet only for an established accepted flow. Ordered stateless rules evaluate each direction independently, so an outbound request can pass while its reply is denied. Priority-stateful mode demonstrates explicit deny selection, including deny-first ties. These are declared policies rather than universal provider rule merging.

### AWS and GCP comparison

AWS: Security groups / network ACL concepts. Google Cloud: VPC firewall rule concepts. Select the provider mapping before loading input. Product names identify concepts; they do not create resources, imply identical APIs or promise equivalent service guarantees.

## When to use

Use this scenario when reviewing Security groups / network ACL concepts or VPC firewall rule concepts: identify the workload assumption, failure boundary and evidence needed for the selected design. Record one alternative and the constraint it changes.

## Interview pitfalls

AWS security groups, NACLs and Google VPC firewall rules differ in attachment, priorities, denies and evaluation. This exercise does not merge every vendor policy layer.
